フォトフレームカメラ v3

追加した機能
・撮影した直後に画像をプレビュー表示
・プレビュー画像の下に「撮り直す」「保存する」ボタン
・撮影しただけでは自動保存しない
・「保存する」を押したときだけ画像を保存
・「撮り直す」でカメラ画面に戻る

前バージョンから継続

・フレーム比率は1080×1400で固定
・端末サイズによる縦横の引き延ばしなし
・前面 / 背面カメラ切り替え
