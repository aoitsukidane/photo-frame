フォトフレームカメラ

使い方
1. frame.png を好きな透過PNGに差し替えてください。
2. index.html と frame.png を同じフォルダに置きます。
3. HTTPSで公開してください。
   例: GitHub Pages / Netlify / Cloudflare Pages
4. スマホでページを開き、カメラを許可します。

操作
- 白い丸: 撮影
- ↺: 前面 / 背面カメラ切り替え
- 撮影した画像は、カメラ映像と frame.png を合成してPNGとして保存します。

フレーム制作のおすすめ
- サイズ: 1080 x 1920 px（縦長スマホ向け）
- 形式: PNG
- 写真を見せたい中央部分は透明にしてください。

注意
- カメラ利用には HTTPS が必要です。
- iPhone / Android のブラウザ挙動により、保存時の表示は多少異なる場合があります。
